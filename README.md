# EEE703128 - B02
## Bộ mã hóa ưu tiên 8 sang 3 có cờ hợp lệ

**Sinh viên:** Vũ Anh Tú  
**Mã sinh viên:** 24100704  
**Học phần:** EEE703128

### 1. Mô tả dự án
Thiết kế mạch mã hóa ưu tiên 8 đầu vào thành 3 bit đầu ra,
kèm theo cờ hợp lệ (Valid).

### 2. Quy ước ưu tiên
- ui_in[7]: Ưu tiên cao nhất.
- ui_in[0]: Ưu tiên thấp nhất.
- uo_out[2:0]: Mã nhị phân của đầu vào có ưu tiên cao nhất đang ở mức 1.
- uo_out[3]: Cờ hợp lệ.
